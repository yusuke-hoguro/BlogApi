# 学習Planテンプレート

このテンプレートは、1つの設計書を完成させるまでの学習内容を、AIエージェントと一緒に計画するために使用します。

## 使い方

1. このファイルを `docs/study/plans/<learning-id>-plan.md` にコピーする。
2. `入力情報` を記入する。
3. AIエージェントに、このPlanと対応する進捗ファイルを読み込ませる。
4. AIエージェントに理解度診断とPlan作成を依頼する。
5. Planのレビュー後、一度に1 Stepずつ学習する。

> `<...>` は記入箇所です。不要な例や案内文は、Plan確定時に削除してください。

---

## AIエージェントへの指示

### Plan作成時

- リポジトリの `AGENTS.md` と、対象領域に対応する `docs/agents/` 配下の資料を先に確認する。
- 実装、設定、既存ドキュメントから確認できる事実を優先し、事実・一般的な推奨・推測を区別する。
- 学習者の理解度診断を行ってから、Stepの数と粒度を決める。
- 既に理解している内容は短くし、未経験または曖昧な内容は細かく分割する。
- 依存関係のあるStepは、前提知識から応用へ進む順番にする。
- 各Stepに、学習者が考える場面と理解を確認する場面を設ける。
- 設計書を完成させるだけでなく、設計理由や代替案を説明できることをゴールに含める。
- Planの最終Stepには、必ず復習・応用を含める。

### 学習進行時

- 一度に扱うのは1 Stepだけとする。
- Step開始時に、目的、学ぶ論点、完了条件を説明する。
- 原則として、学習者より先に完成回答や完成した設計書を提示しない。
- 最初に学習者へ、予想、説明、判断、調査または草案作成を促す。
- 学習者の回答後に、正しい点、不足、誤解と、その理由をフィードバックする。
- 学習者が明示的に依頼した場合は、完成例や模範回答を提示してよい。
- 成果物が作成されただけではStepを完了にしない。学習者が重要な内容を自分の言葉で説明できるか確認する。
- 完了条件を満たさない場合は、同じStep内で補足説明または再演習を行う。
- 学習者の確認を得るまで次のStepへ進まない。
- Step完了時に、進捗ファイルへ記録する内容を整理する。
- Planの変更が必要な場合は、変更理由と後続Stepへの影響を説明し、学習者の確認後に反映する。

## Plan変更ルール

- Planは学習中の理解度や新しく判明した前提に応じて変更してよい。
- AIエージェントは、変更前に理由と後続Stepへの影響を提示する。
- 学習者の確認後、Planと進捗ファイルの変更履歴を更新する。
- 過去の完了記録は削除せず、再確認が必要な場合はその理由を残す。
