# 学習進捗管理テンプレート

このテンプレートは、学習Planの進捗と理解の証拠をテーマごとに記録し、別のセッションでも学習を正確に再開するために使用します。

## 使い方

1. このファイルを `docs/study/progress/<learning-id>-progress.md` にコピーする。
2. 対応する学習Planと同じ学習IDを設定する。
3. AIエージェントとの学習開始時に、Planとこの進捗ファイルの両方を読み込ませる。
4. Step完了時とセッション終了時に更新する。

> `<...>` は記入箇所です。不要な例や案内文は、進捗ファイル作成時に削除してください。

---

## AIエージェントへの再開指示

学習を再開するときは、次の順番で確認してください。

1. `対応するPlan` を読み、全体のゴールとStepの依存関係を確認する。
2. このファイルの `現在地`、`未解決事項`、`次回の開始地点` を確認する。
3. 完了済みStepの理解の証拠と、Plan変更履歴を確認する。
4. 学習者に現在地と今回行う1 Stepを短く説明する。
5. `次回最初に行うこと` から再開し、一度に複数Stepへ進まない。

進捗更新時は、次のルールを守ってください。

- 実施した作業と、理解できたことを分けて記録する。
- 成果物が作成されただけではStepを完了にしない。
- 完了条件を満たした証拠と、学習者の完了承認を記録する。
- 理解が曖昧な事項を、完了済みとして扱わない。
- AIの推測で進捗を補完せず、不明な事項は `要確認` と記録する。
- Planを変更した場合は、理由と影響を変更履歴へ残す。
- 秘密情報や生の認証情報は記録しない。
